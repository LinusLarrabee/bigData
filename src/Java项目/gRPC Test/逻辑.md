### 注释

本工具默认删除所有注释

## HEAD

包含 import，package等信息

本工具默认使用proto3，作为java开发工具，暂时只处理传入文件的java_multiple_files和java_package并写入最终文件，对于嵌套引入其他proto文件的对应选项，仅做读取使用

对于import的proto，采用图论相关逻辑，读取所有依赖文件。

关于import涉及到classpath即引用其他包文件的路径问题，增加新可选输入参数为路径依赖。

java_package用于描述生成的java文件路径，package用于本地相互引用情况下的路径问题。

本工具最后生成单一proto文件，以避免在生成项目后出现路径依赖相关问题，因此实际上可以不处理message相关内容只对rpc进行分析。**（不想进行验证**

一种是构建嵌套message形式，由于调用的层次不同，本方式在maven下会与其他方式产生冲突，实际使用postman与protoc则不会有问题。

## Body

本部分逻辑上以此开头的有service，message和enum三种可选项，方法上使用bracket的闭包性将代码分块处理。

service部分比较简单，将对应代码块按行读取保存即可。

目前暂时不支持含有函数体（一般也认为没有函数体）

**目前暂时仅支持unary传输**



enum的解析目前仅将所有内容存储到单行字符串中

message需处理嵌套问题，包括

1. message在不同文件中，包含或不包含package名
2. message在同一文件中，位于被引用位置上层的不同层级
3. message重名

此外，需处理与enum嵌套（同时需解决上述问题），以及map的特殊处理

此外，上述处理的每一个环节需要讨论google处理，具体如下

1. service直接引用google
2. message包含google信息
3. enum包含google信息
4. map参数包含google信息
