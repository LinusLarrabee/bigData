## 较为原始的版本

### Proto文件部分

hello.proto

```protobuf
syntax = "proto3";

package com.xxx.tutorial.demo.grpc;

option java_multiple_files = true;
option java_package = "com.xxx.tutorial.demo.model";  
option java_outer_classname = "Hello";

message HelloRequest{  
    string name  = 1;  
    int32 id    = 2;  
}  
message HelloResponse{  
    string message = 1;  
}  
```

hello_service.proto

```protobuf
syntax = "proto3";

package com.xxx.tutorial.demo.grpc;


option java_multiple_files = true;
option java_package = "com.xxx.tutorial.demo.service"; 
option java_outer_classname = "GreetingService";

import "hello.proto";

service HelloService{  
    rpc sayHello(HelloRequest) returns (HelloResponse);  
}  
```

注意不要出现重名问题

编译过程使用maven-protobuf插件，使用 custom ，或直接mvn compile，可以将置于 "src/main/proto" 路径下的文件编译到 "java_package" 中。

对于生成的一系列文件，对服务端，需要编写serviceImpl文件以及server文件

### Service部分

ServiceImpl

```java

package com.tplink.tauc.grpcapiinterfacemanagetool.service;
import com.tplink.tauc.grpcapiinterfacemanagetool.model.HelloRequest;
import com.tplink.tauc.grpcapiinterfacemanagetool.model.HelloResponse;
import io.grpc.stub.StreamObserver;
import java.util.logging.Logger;

public class GreetingServiceImpl extends HelloServiceGrpc.HelloServiceImplBase {

    private static final Logger logger = Logger.getLogger(GreetingServiceImpl.class.getName());

    public void sayHello(HelloRequest request, StreamObserver<HelloResponse> responseObserver) {

        logger.info(String.format("sayHello方法调用的请求参数信息: name={%s}, id={%d}", request.getName(), request.getId()));

        HelloResponse reply = HelloResponse.newBuilder().setMessage(String.format("Hello, %s", request.getName()))
                .build();

        responseObserver.onNext(reply);
        responseObserver.onCompleted();
    }

}
```

Grpc.Client

```java
package com.tplink.tauc.grpcapiinterfacemanagetool.channel;


import com.tplink.tauc.grpcapiinterfacemanagetool.model.HelloRequest;
import com.tplink.tauc.grpcapiinterfacemanagetool.model.HelloResponse;
import com.tplink.tauc.grpcapiinterfacemanagetool.service.HelloServiceGrpc;
import io.grpc.ManagedChannel;
import io.grpc.ManagedChannelBuilder;
import io.grpc.reflection.v1alpha.ServerReflectionGrpc;
import lombok.extern.slf4j.Slf4j;

@Slf4j
public class ReflectionClient {

    public static void main(String[] args) throws InterruptedException {
        // 构建 Channel
        ManagedChannel channel = ManagedChannelBuilder.forAddress("127.0.0.1", 1788)
                .usePlaintext()
                .build();

        HelloServiceGrpc.HelloServiceBlockingStub helloServiceBlockingStub = HelloServiceGrpc.newBlockingStub(channel);
        HelloResponse helloResponse = helloServiceBlockingStub.sayHello(HelloRequest.newBuilder().setName("dddd").build());
        System.out.println(helloResponse.getMessage());
//
//        // 使用 Channel 构建 BlockingStub
        ServerReflectionGrpc.ServerReflectionStub reflectionStub = ServerReflectionGrpc.newStub(channel);
    }
}
```

Grpc.Server

```java
package com.tplink.tauc.grpcapiinterfacemanagetool.channel;

import com.tplink.tauc.grpcapiinterfacemanagetool.service.GreetingServiceImpl;
import io.grpc.Server;
import io.grpc.netty.shaded.io.grpc.netty.NettyServerBuilder;
import lombok.SneakyThrows;
import lombok.extern.slf4j.Slf4j;

import java.net.InetSocketAddress;
import java.util.concurrent.TimeUnit;

@Slf4j
public class ReflectionServer {

    @SneakyThrows
    public static void main(String[] args) {
        // 构建 Server
        Server server = NettyServerBuilder.forAddress(new InetSocketAddress(1788))
                // 添加服务
//                .addService(new HelloGrpcService())
                .addService(new GreetingServiceImpl())
                // 添加反射服务
//                .addService(ProtoReflectionService.newInstance())
                .build();

        // 启动 Server
        server.start();
        log.info("服务端启动成功");

        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            try {
                server.awaitTermination(10, TimeUnit.SECONDS);
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        }));

        // 保持运行
        server.awaitTermination();
    }
}
```



## 现有开发版本

使用 ```@GrpcService``` 注解来标注上述ServiceImpl，并将所需端口放入到 resources/application.properties 中省去对 Server文件的使用，进而对服务端只需生成原有的ServiceImpl，并可以直接命名为 Server 。

对于客户端使用 ```@GrpcClient``` 注解

```properties
grpc.server.port=1555
grpc.server.host=0.0.0.0
```
