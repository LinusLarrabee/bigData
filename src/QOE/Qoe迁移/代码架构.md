TAUC-wifi-management架构设计



```
tauc-wifi-management
├─helm
│ └─tpuc-wifi-management
├─src
│ ├─main
│ │ ├─container
│ │ ├─java
│ │ │ └─com.tplink.shd.tauc.wifimanagement
│ │ │  ├─client       ---------业务调用其他微服务的客户端，仅此处涉及到的
│ │ │  │ ├─feign.client
│ │ │  │ ├─feign.service
│ │ │  │ └─dto/enums/constants 仅此处涉及的常变量，枚举
│ │ │  ├─common
│ │ │  │ ├─annotation ---------包含aspect
│ │ │  │ ├─constant
│ │ │  │ ├─response
│ │ │  │ ├─migration
│ │ │  │ └─enums
│ │ │  ├─config
│ │ │  | ├─props        ---------业务配置，读yaml
│ │ │  | ├─infra        ---------内外中间件配置，读yaml
│ │ │  | └─share        ---------业务对中间件配置部分
│ │ │  ├─entity
│ │ │  │ ├─eventfrontend      分业务划分entity
│ │ │  │ ├─eb/es/alert
│ │ │  │ | └─dto
│ │ │  │ └─business   ---------非本服务相关DTO类
│ │ │  └─port         ---------业务对外暴露的入口
│ │ │    ├─controller
│ │ │    ├─subscriber
│ │ │    ├─grpc
│ │ │    └─xxljob
│ │ │  ├─repository
│ │ │  │ ├─cache
│ │ │  │ │ ├─po
│ │ │  │ │ ├─mapper
│ │ │  │ │ └─dao
│ │ │  │ └─cassandra
│ │ │  │ │ ├─dao
│ │ │  │ │ ├─jpadao
│ │ │  │ │ ├─key
│ │ │  │ │ ├─mapper
│ │ │  │ │ └─po
│ │ │  ├─service
│ │ │  │ ├─ef/eb/es..
│ │ │  │ ├─utils      ---------放这里是因为有相当多解析方法
│ │ │  │ | ├─util
│ │ │  │ | └─mapper   ---------dto之间的转换
│ │ │  │ └─business   ---------非本服务相关DTO类
│ │ ├─proto
│ │ └─resources
│ └─test
```

代码整体框架基本遵循MVC架构

中间件配置，其他微服务客户端这两部分使用单独的dto/enums/constants
