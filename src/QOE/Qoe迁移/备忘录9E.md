# 细节问题

dto类型以network的代码为准，因此原始wii-management迁移只处理service部分。





# 框架

event-frontend：原event-frontend的解析部分

event-backend：原network关于分数计算和落库部分

event-show：原network与agg交互部分

wifi-management：原来wifi-management的服务部分，dto使用backend的保持统一



# 链路重构

原来network到wifi-management之间使用grpc通信传递到S3，现在删除grpc通信。

原来eventfrontend-network使用kafka通信，现在将kafka的传递前置。
