Qoe链路配置梳理



配置上分为微服务及中间件两部分。中间件包括ec2裸机搭建的中间件，包括Mongo，kafka，cassandra，及aws托管的中间件mysql及redis。微服务包括代码资源硬件配置，及资源调度，如线程池配置

### 中间件资源：

Mongodb：

|         |              | pet           | prd-aps1      | 影响 |
| ------- | ------------ | ------------- | ------------- | ---- |
| arbiter | 仲裁节点     | 2*t3.micro    | 2*m7i.large   | 小   |
| backup  | 备份         | 0             | 1*m7i.large   |      |
| config  | 配置服务器   | 3*t3.small    | 3*m7i.large   | 大   |
| mongos  | 路由服务     | 2*m7i.2xlarge | 2*m7i.2xlarge | 大   |
| shard   | 实际存储数据 | 2*m7i.2xlarge | 2*m7i.2xlarge |      |

kafka与cassandra机器资源如下

|           | pet                    | prd-aps1                    |
| --------- | ---------------------- | --------------------------- |
| kafka     | 3*t3.medium, only spbu | 3*m7i.large, only spbu      |
| cassandra | 3*m6i.large, only spbu | 33*r6i.xlarge, tplink share |
