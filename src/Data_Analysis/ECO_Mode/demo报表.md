

# QoE数据探索平台Demo

就他是先去过滤地区和频段，然后按照时间的颗粒度将每一个用户的数据求平均，然后再找一个指标按这个指标把所有的数据排序，然后找出每个时间颗粒度这个指标排75%的客户，可能不同时间颗粒度在75%处的客户不一样，他有一整串平均下来的指标数据，然后把这整串数据都拉出来，然后这就是一列的很多点，然后时间轴就是把时间颗粒度的每一个点给连成线

左侧会提供可选项

1. **选择Region和Band**：
   - 两个下拉框分别用于选择区域（Region）和频段（Band）。
   - Options: 'Region': 'use1', 'aps1', 'euw1'; 'Band': '2.4g', '5g', '6g'.
2. **选择时间粒度**：
   - 下拉框选择时间粒度。
   - Options: '15 minutes', '1 hour', '1 day', '7 days'.
3. **选择起始时间**：
   - 日期选择器和时间选择器。
   - 起始时间右边。
4. **选择组别**：
   - 下拉框选择组别。
5. **小时和分钟输入框**（仅当时间粒度为天内时显示）：
   - 输入框用于输入具体的小时和分钟。
6. **选择百分位**：
   - 数字输入框和滑块（Slider）。
   - 数字输入框用于输入具体的百分位值。
   - 滑块用于拖动选择百分位。





1. Filter部分：

   1. 选择Region，aps1/use1/euw1/All
   2. 选择Band，2.4g/5g/6g
   3. 选择时间范围
      1. 细化到小时和分钟，使用UTC时间
      2. 时间颗粒度到天：目前使用UTC时间，计划使用utc/utc+8/utc-5
      3. **问题1：求平均的话可能部分设备数据不齐，即假设不同时间上传的设备数不同，如何使用？**
         1. 平均值计算方式：先聚合到1H，再对1H聚合的数据求平均；or 1天的数据是对一天内所有收集的数据求平均。注：7d的数据仅支持对1d的数据再平均。
         2. 可能导致异常数据被削减或者放大。

2. 百分位

   1. 假设不同时间上报的设备数量不同

   2. 将数据从离散点排序拉成Uniform分布，即假设10台设备，排名第一的占据区间[0,0.1]的分布。

   3. 加权方式
   
      1. 假设某指标原始数据是：39,39,70,71,74,78,83,83,86,98
   
      2. | 起始百分位 | 结束百分位 | 计算方式                | 计算结果 |
         | ---------- | ---------- | ----------------------- | -------- |
         | 95%        | 99%        | d10                     | 98       |
         | 90%        | 100%       | d10                     | 98       |
         | 95%        | 95%        | d10                     | 98       |
         | 90%        | 90%        | (d9+d10)/2              | 92       |
         | 82%        | 92%        | (d9*0.8+d10\*0.2)/1     | 88.4     |
         | 85%        | 92%        | (d9\*0.5+d10\*0.2)/0.7  | 89.4     |
         | 75%        | 95%        | (d8/*0.5+d9+d10/*0.5)/2 | 88.25    |
   
         
   
      3. 取5%-15%的数据就是$d1\times0.5+d2\times0.5$
   
      4. 取2%-15%的数据就是$(d1*0.8+d2*0.5)/1.3$
