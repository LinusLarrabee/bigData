# 无线漫游技术

802.11 k/v/r

k测量，v执行，r优化

注意ap-sta的距离，即rssi可由11k测量



rssi = rcpi/2-110，只是经验公式，两个数据没有直接关联。



roaming发起者可以是ap也可以是sta，sta的私有协议，不进行query和btm(BSS Transition Management)操作，只是漫游



漫游阈值的设置需要增加随机数，避免一直漫游
